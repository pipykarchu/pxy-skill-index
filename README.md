# PXY 技能索引

产品经理技能目录、推荐工作流与加密下载站。

- 页面入口：`index.html`
- 公开目录：`catalog-public.json`
- 完整索引：237 个技能、8 个工作流
- 加密下载：`downloads/pxy-skills-workflows.pxy`
- GitHub Pages：推送到 `pipykarchu/pxy-skill-index` 的 `main` 分支后自动发布

页面与本地产品经理技能索引使用同款布局。下载密钥只用于浏览器本地解密，公开目录不保留原始 ZIP。

加密合集当前包含 13 个通过许可、敏感信息和结构检查的技能包，以及 8 个工作流定义。许可未知或明确禁止公开分发的技能仍可浏览，但不会进入下载包。
